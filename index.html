注意事項

請放心下載與安裝。因為是全新版本、尚未累積瀏覽器下載紀錄，部分瀏覽器可能會顯示安全提示，這是正常現象，並非病毒或惡意程式。

瀏覽器擋下下載了嗎？點此看解決方法

Edge：下載列點選檔案旁的「...」或箭頭 →「保留」；若執行時跳出「Windows 已保護您的電腦」，點左下角「其他資訊」→「仍要執行」即可。

Chrome：下載列點選檔案旁的箭頭 →「保留」或「仍要下載」。

Firefox：下載提示選擇「保留檔案」；若已被封鎖，點右上角下載圖示（或 Ctrl+Shift+Y 開啟「程式庫」→「下載」），找到檔案後點「允許下載」。

安裝後打不開嗎？點此看解決方法

方法一：解除封鎖（最快）
打開 C:\Program Files\TRL Bot\　→　右鍵點 TRL_Bot.exe →「內容」　→　右下角看到「解除封鎖」核取方塊　→　勾起來 →「套用」　→　重新啟動程式。

方法二：關閉 Smart App Control（Windows 11 才有）
開始 → 搜尋「Windows 安全性」　→「應用程式與瀏覽器控制」→「Smart App Control 設定」　→　改成「關閉」　→　重新安裝／啟動。

方法三：防毒軟體排除
如果有安裝卡巴斯基、McAfee 等第三方防毒，把 C:\Program Files\TRL Bot\ 整個資料夾加入白名單。

被「Smart App Control」擋住安裝了嗎？點此看解決方法

執行安裝檔時如果跳出「這個應用程式已封鎖」或提示 Smart App Control 已阻止，代表 Windows 11 的智慧應用程式控制把安裝檔判定為未知來源而擋下，需要先關閉這個功能才能安裝：

步驟：
開始 → 搜尋「Windows 安全性」 → 「應用程式與瀏覽器控制」 → 「Smart App Control 設定」 → 改成「關閉」。

⚠ 關閉後請重新下載一次安裝檔再執行（已被擋下的舊檔案可能仍標記為封鎖），另外 Smart App Control 關閉後無法再重新開啟，只能透過「重灌 Windows」恢復，這是微軟的限制，並非本軟體造成。

尼克．李森在新加坡操盤日經期貨，一次虧損後不願停損，反而藏進錯帳戶並加碼攤平，賭市場反彈一次就能抹平。1995年神戶大地震重擊日本股市，虧損雪球式擴大到13億美元，超過銀行全部資本，238年歷史的霸菱銀行最終以一英鎊象徵性價格賣出。

傑洛米．柯維耶利用後勤系統漏洞，建立遠超授權額度的歐股指數期貨部位，帳面虧損後不甘認賠，反覆用假交易掩蓋真實部位並加碼翻本，規模一度近500億歐元。金融海嘯來襲，部位全面失控，銀行被迫三天內緊急平倉，認列49億歐元虧損。

住友商事事件（1996）

濱中泰男人稱「Mr. Copper」，長年在倫敦金屬交易所操縱銅市場，虧損擴大後仍不願認錯，靠未經授權的交易掩蓋帳目長達十年之久。真相曝光時，累計虧損高達26億美元，成為當時全球最大宗商品交易詐欺醜聞之一。
